name: record-uat
description: Record user acceptance test results in the backlog. Use for From Problem to Product, Sitting E3. The user types the results after asking for this skill.
---

1. Read the results the user typed.
2. Create BACKLOG.md if it doesn't exist, with four sections: Now,
   Next (v2), Later (v3), Done.
3. Add each problem as an item. Label each one Bug (something
   broken) or Idea (something new).
4. Put bugs in Now. Put ideas in v2 or v3.
5. Show the user the backlog.
