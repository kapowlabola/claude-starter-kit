---
name: start-session
description: Start a work session. Use when the user says they are starting, opening, or picking up their project.
---

1. Pull the latest changes from GitHub.
2. Read CLAUDE.md, PROGRESS.md, and BACKLOG.md (if it exists).
3. In plain English, tell the user in 5 sentences or fewer:
   - what was done last time
   - what is next
   - anything that was left broken or unfinished
4. Ask the user what they want to work on today. Don't start any
   work until they answer.
