---
name: end-session
description: End a work session. Use when the user says they are stopping, done for the day, or closing the project.
---

1. Update PROGRESS.md: add today's date, what was done today, and
   what is next.
2. If anything is broken or half-finished, write that down in
   PROGRESS.md too.
3. Save a checkpoint: commit all changes to main with a short
   message describing today's work, then push to GitHub.
4. Tell the user in one or two sentences that their work is saved
   and what to do first next time.
