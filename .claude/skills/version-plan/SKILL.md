description: Split PRD requirements into v1, v2, and v3. Use for From Problem to Product, Sitting B3.
---

1. Read docs/PRD.md.
2. Add a section called "Version plan". Assign every requirement to:
   - v1 (MVP): only what's needed to fix problem #1. Keep it small.
   - v2 (MVCR): what's needed for daily use.
   - v3: everything else.
3. Show the plan as a table and explain why each item is in its
   version.
4. If v1 has more than a handful of requirements, suggest what could
   move to v2.
