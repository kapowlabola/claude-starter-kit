---
name: explain
description: Explain the most recent change in plain English. Use when the user asks what just happened, what changed, or what something means.
---

1. Look at the most recent change you made, or the thing the user is
   asking about.
2. Explain it as if the user has never coded:
   - what changed, in one sentence
   - why it was needed
   - how the user can see or test it
3. Don't use technical words without explaining them. Keep it under
   150 words.
