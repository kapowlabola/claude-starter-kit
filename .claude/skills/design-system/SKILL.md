1. Read docs/PRD.md.
2. Suggest two design system options. Each includes colors, fonts,
   text sizes, button styles, and spacing.
3. Both must be easy to read: text at least 16 pixels, high
   contrast, big buttons.
4. Wait for the user to choose. Then save the chosen option as
   docs/design-system.md.
