description: Turn photographed discovery notes into a written summary. Use for From Problem to Product, Sitting B1.

1. Read every photo in docs/discovery.
2. Write docs/discovery.md with four sections:
   - The problem (context, history, challenges, goal)
   - How it works today
   - Problems, ranked in the order the user numbered them
   - Ideas
3. If any writing is unclear, ask the user instead of guessing.
4. Show the user a short summary and ask if anything is missing.
