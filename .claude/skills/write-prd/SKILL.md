---
name: write-prd
description: Write a Product Requirements Document (PRD). Use for From Problem to Product, Sitting B2.
---

1. Read docs/discovery.md.
2. Write docs/PRD.md with these sections:
   1. Problem statement (2 to 3 sentences)
   2. Users: who they are and what they need
   3. Goals and how we'll measure success
   4. Current workflow and problems
   5. Requirements: numbered (R1, R2...). For each one, write
      acceptance criteria: plain sentences that say how to check it
      works.
   6. Out of scope: things we are deliberately NOT building
   7. Open questions
3. Write in plain English. Don't write any code.
