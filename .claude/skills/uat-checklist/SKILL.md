---
name: uat-checklist
description: Create a printable user acceptance test (UAT) checklist. Use for From Problem to Product, Sitting E1.
---

1. Read the acceptance criteria in docs/PRD.md for the current
   version.
2. Create docs/UAT.md: one row per acceptance criterion, written as
   a simple task in plain English, with columns for Pass, Fail, and
   Notes.
3. At the top, write the steps to open the software.
