---
name: backlog
description: Show or update the project backlog. Use when the user asks about the backlog, wants to add an idea, or asks what to do next.
---

1. Read BACKLOG.md. If it doesn't exist, create it with four
   sections: Now, Next (v2), Later (v3), Done.
2. If the user gave a new idea or bug, add it to the right section
   and confirm.
3. Otherwise, show the backlog and recommend the single most
   important next item, with one sentence on why.
4. Never start work on an item unless the user asks for it by
   number.
