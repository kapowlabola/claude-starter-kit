# Claude Starter

A starter project for the guide **Start Coding with Claude (Mac)**.

To use it, click **Use this template > Create a new repository**, choose **Private**, and follow Part 2 of the guide.

## What's inside
- `.devcontainer/devcontainer.json`: builds the sealed container Claude works in
- `.claude/skills/`: saved routines. Open any `SKILL.md` to read exactly what it tells Claude to do.
- `CLAUDE.md`: rules Claude reads at the start of every conversation
- `PROGRESS.md`: what's done and what's next
